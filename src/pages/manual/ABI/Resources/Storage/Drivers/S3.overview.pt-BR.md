# S3

`S3` é o driver do Storage para o Amazon S3 e serviços compatíveis com S3 (MinIO, Cloudflare R2,
Wasabi). Além do contrato do [Storage](/guide/storage/overview/) que todo disk compartilha, ele
tem três coisas só dele, para bytes que não devem passar pelo seu servidor:

- **URLs pré-assinadas** — um link que deixa alguém ler ou escrever um objeto por um tempo
  limitado, sem credenciais;
- **o handle `Uploads`** — um Multipart Upload cujas partes o navegador envia direto para o
  bucket;
- **leituras por faixa** — uma janela de um objeto em vez dele inteiro.

Elas existem só no S3: acesse-as no próprio driver, não na fachada `Storage`.

```php
use Bootgly\ABI\Resources\Storage;

$Storage = new Storage([
   'disks' => [
      'media' => [
         'driver' => 's3',
         'root'   => 'uploads',      // todo path abaixo fica dentro deste prefixo
         'bucket' => 'assets',
         'region' => 'us-east-1',
         'key'    => '…',
         'secret' => '…',
      ],
   ],
]);

/** @var Storage\Drivers\S3 $S3 */
$S3 = $Storage->open('media');
```

Todo método abaixo retorna `false` quando é recusado ou falha, e deixa o motivo em `$S3->error`.

## Um link de download com prazo

```php
$URL = $S3->presign('GET', 'invoices/2026-11.pdf', 300);
// https://assets.s3.us-east-1.amazonaws.com/uploads/invoices/2026-11.pdf?X-Amz-Algorithm=…

if ($URL === false) {
   // $S3->error diz o motivo
}
```

Quem abrir a URL nos próximos 300 segundos baixa aquele objeto — sem sessão, sem credenciais, sem
requisição passando pela sua aplicação. O `presign()` não faz requisição nenhuma: ele só assina.

Para o navegador salvar o arquivo com um nome, ou para fixar o tipo, passe os overrides de
resposta. Eles são assinados junto com a URL, então quem a recebe não consegue alterá-los:

```php
$URL = $S3->presign('GET', 'invoices/2026-11.pdf', 300, [
   'response-content-disposition' => 'attachment; filename="invoice.pdf"',
   'response-content-type' => 'application/pdf',
]);
```

Um `PUT` pré-assinado deixa quem tem a URL gravar um objeto em uma única requisição:

```php
$URL = $S3->presign('PUT', 'avatars/42.png', 60);
```

> [!WARNING]
> Só o método, o objeto, o prazo e a query são assinados — o corpo não. Quem tem uma URL de
> `PUT` escolhe os bytes, o tamanho e o `Content-Type`. Para receber uploads de quem você não
> confia, use o handle `Uploads` abaixo: ele fixa o tipo no servidor e deixa você conferir o que
> chegou antes de o objeto existir.

### O que é uma URL pré-assinada

Uma URL pré-assinada é um segredo que funciona até expirar. Qualquer um que a leia — em um log,
em um referrer, em uma captura de tela compartilhada — pode usá-la. Então:

- mantenha o prazo curto: segundos ou minutos, nunca o máximo de 7 dias por hábito;
- nunca a registre em log, nem a coloque em uma mensagem de erro ou exceção;
- entregue-a ao cliente que a pediu, por HTTPS, e a mais ninguém.

Uma URL não pode ser revogada individualmente: ela para de funcionar quando expira, ou quando a
chave de acesso que a assinou é desativada.

O que ela autoriza é estreito por construção:

| | |
|---|---|
| **Método** | `GET`, `HEAD` ou `PUT` — aquele para o qual foi assinada. Apagar, listar e as etapas do multipart nunca são pré-assinados aqui. |
| **Objeto** | Aquele único path, resolvido dentro do `root` do disk como qualquer outra operação. `../` não sai do prefixo, e o próprio root é recusado. |
| **Prazo** | De 1 a 604800 segundos (7 dias), contados pelo serviço a partir do momento da assinatura. |
| **Query** | Só os seis overrides `response-*`, em `GET`/`HEAD`. Qualquer outra coisa — um sub-recurso, um parâmetro `x-amz-*` — é recusada. |

## Upload do navegador direto para o bucket

Um arquivo grande não precisa passar pelo seu servidor. O servidor abre um Multipart Upload,
assina uma URL por parte, o navegador faz o `PUT` de cada parte no bucket, e o servidor as junta.

O handle é `$S3->Uploads`. Ele não guarda estado: um upload atravessa várias requisições, então
toda etapa recebe o path do objeto e o id do upload.

**1. Abra o upload** — o servidor decide o path, o tipo e os metadados:

```php
$id = $S3->Uploads->create('videos/42/source.mp4', [
   'type' => 'video/mp4',
   'meta' => ['owner' => '42'],
]);
// guarde o $id junto do seu próprio registro do upload e então envie-o ao cliente
```

**2. Assine cada parte** — conforme o cliente as pede:

```php
$URL = $S3->Uploads->sign('videos/42/source.mp4', $id, $part, 900);   // $part: 1..10000
```

O cliente envia os bytes daquela parte com um `PUT` simples para a URL — nenhum header é
necessário. Uma parte enviada de novo substitui a anterior, então uma parte que falhou é
simplesmente reenviada.

**3. Confira o que chegou e então complete:**

```php
$Parts = $S3->Uploads->list('videos/42/source.mp4', $id);
// [1 => ['etag' => '"9b2c…"', 'size' => 8388608], 2 => […], …] — ou false

$size = 0;
foreach ($Parts ?: [] as $Part) {
   $size += $Part['size'];
}

if ($Parts === false || $Parts === [] || $size > 2_000_000_000) {
   $S3->Uploads->abort('videos/42/source.mp4', $id);
}
else {
   $S3->Uploads->complete('videos/42/source.mp4', $id, $Parts);
}
```

O `list()` é o que o serviço realmente tem: os tamanhos são medidos pelo serviço, não informados
por quem enviou, e os ETags são os que o `complete()` precisa. Completar a partir do `list()`
significa que o navegador nunca precisa ler um header de resposta, então as regras de CORS do
bucket só precisam permitir o `PUT`.

**Retomar** — o `list()` também é como um upload interrompido continua: as partes que já estão
lá não precisam ser enviadas de novo.

**Abortar** — um upload que nunca é completado mantém suas partes, e o serviço cobra por elas.
Chame `abort()` quando o usuário cancelar ou uma conferência falhar, e configure no bucket uma
regra de ciclo de vida que aborte uploads incompletos depois de alguns dias, para os que ninguém
cancela.

> [!IMPORTANT]
> Trate o id do upload como parte do seu próprio estado. Guarde-o no servidor junto do registro
> a que ele pertence (quem começou, qual path), e tire o path desse registro — nunca da
> requisição. O handle recusa um id que não seja um token simples, mas não tem como saber de
> quem é o upload.

### Notas para serviços compatíveis com S3

- **Partes de tamanho igual.** O Amazon S3 só exige que toda parte, menos a última, tenha pelo
  menos 5 MiB. O Cloudflare R2 exige também que toda parte, menos a última, tenha o **mesmo**
  tamanho, e recusa a conclusão caso contrário. Escolha um tamanho de parte no cliente (8 ou
  16 MiB, por exemplo), corte o arquivo em partes exatamente desse tamanho, e confira os tamanhos
  no `list()` antes de completar.
- **Endpoints `http`.** Um disk cujo `endpoint` é `http://…` (um MinIO local, um fake de teste) é
  recusado na construção, a menos que defina `'insecure' => true`, e suas URLs pré-assinadas
  também são `http`: a URL — um segredo — e os bytes trafegam em texto claro. Use só em
  desenvolvimento.

## Ler uma janela de um objeto

O `read()` recebe um offset e um tamanho depois do sink:

```php
$Sink = fopen('php://memory', 'r+');

$S3->read('videos/42/source.mp4', $Sink, 0, 1024);          // os primeiros 1024 bytes
$S3->read('videos/42/source.mp4', $Sink, 1_048_576, 4096);  // 4096 bytes a partir do offset 1 MiB
$S3->read('videos/42/source.mp4', $Sink, 1_048_576);        // do offset 1 MiB até o fim
```

O sink nunca recebe um byte de fora da janela:

- uma janela que passa do fim do objeto é cortada no fim;
- um offset no fim ou depois dele é `false` (`range not satisfiable (HTTP 416)`), sem nada
  escrito;
- um endpoint que ignora a faixa e responde o objeto inteiro, ou responde outra janela, é
  `false`, sem nada escrito — nunca os bytes errados no sink.

Uma janela ainda pode ser cortada no caminho: a conexão cai, ou a resposta termina antes do
último byte. O `read()` então é `false` com os primeiros bytes da janela já no sink. Quando você
anexa janelas a um arquivo, anote a posição do sink antes de cada `read()` e trunque de volta
para ela em caso de `false`, antes de tentar de novo:

```php
$position = ftell($Sink);

if ($S3->read('videos/42/source.mp4', $Sink, $offset, $length) === false) {
   ftruncate($Sink, $position);
   fseek($Sink, $position);
   // tente de novo, ou desista — $S3->error diz o motivo
}
```

Sem offset e sem tamanho, o `read()` é a leitura do objeto inteiro que todo driver tem. A janela
faz parte só do `S3::read()`: o `Storage::read()` e os outros drivers continuam com
`read($path, $sink)`.

## Assinar requisições por conta própria

O driver assina com o `Storage\Drivers\S3\Signer`, um assinador AWS Signature Version 4 que você
pode usar sozinho — para chamar uma operação do S3 que o driver não encapsula, ou outro serviço
que aceite a mesma assinatura:

```php
use Bootgly\ABI\Resources\Storage\Drivers\S3\Signer;

$Signer = new Signer($key, $secret, 'us-east-1');

// Header auth: os headers a enviar com a requisição
$headers = $Signer->sign(
   'GET',
   'assets.s3.us-east-1.amazonaws.com',
   '/uploads/a%20b.txt',                 // já percent-encoded
   ['versionId' => '3'],                 // raw: codificado e ordenado pelo assinador
   ['Range' => 'bytes=0-9'],             // assinado, e enviado por você
   hash('sha256', '')                    // o SHA-256 do corpo
);

// Query auth: a query string de uma URL pré-assinada
$query = $Signer->presign('GET', 'assets.s3.us-east-1.amazonaws.com', '/uploads/a%20b.txt', [], 300);
$URL = "https://assets.s3.us-east-1.amazonaws.com/uploads/a%20b.txt?{$query}";
```

O assinador assina o que recebe: diferente do `S3::presign()`, ele não tem prefixo de root nem
lista de métodos ou parâmetros permitidos. Ele lança `InvalidArgumentException` para entrada que
não é canônica — uma quebra de linha no método, no host, no path, em um header ou no hash do
payload, um `?` no path, um prazo fora de 1..604800, um parâmetro de autenticação `X-Amz-*` na
query. Valores de query são dados: o que eles tiverem é percent-encoded.

## Referência

### S3

```php
public function presign (string $method, string $path, int $expires, array $query = []): string|false
```

Pré-assina uma requisição para um objeto e retorna sua URL absoluta, sem fazer requisição.
`$method` é `GET`, `HEAD` ou `PUT`; `$expires` é o prazo em segundos, 1..604800; `$query` recebe
os overrides `response-content-disposition`, `response-content-type`, `response-cache-control`,
`response-content-encoding`, `response-content-language` e `response-expires` de um `GET`/`HEAD`,
como strings. Retorna `false` — motivo em `$error` — para qualquer outro método ou parâmetro, um
prazo fora do intervalo, o root do disk como path, ou um disk sem `key`/`secret`.

```php
public function read (string $path, $sink, int $offset = 0, null|int $length = null): bool
```

Transmite o objeto — ou a janela de `$length` bytes a partir de `$offset` — para o resource
gravável `$sink`. Um tamanho `null` lê até o fim. Retorna `false` para um offset negativo, um
tamanho menor que 1, um objeto inexistente, um offset no fim ou depois dele, ou uma resposta que
não é a janela pedida — todos sem nada escrito — e para uma janela cortada no caminho, com os
primeiros bytes já escritos.

```php
public private(set) Uploads $Uploads
```

O handle de Multipart Upload do disk.

### S3\Uploads

```php
public function create (string $path, array $options = []): string|false
```

Inicia um Multipart Upload para o objeto e retorna o id do upload. `$options` são as opções de
escrita: `type` (Content-Type) e `meta` (um mapa `x-amz-meta-*`).

```php
public function sign (string $path, string $id, int $part, int $expires): string|false
```

Pré-assina o `PUT` de uma parte (1..10000) daquele upload e retorna sua URL, sem fazer
requisição. `$expires` é o prazo em segundos, 1..604800.

```php
public function list (string $path, string $id): array|false
```

Lista todas as partes que o serviço tem para o upload, seguindo todas as páginas:
`[número => ['etag' => string, 'size' => int]]`, em ordem crescente. Retorna `false` quando
qualquer página falha ou está malformada — nunca uma lista parcial.

```php
public function complete (string $path, string $id, array $parts): bool
```

Junta as partes no objeto. `$parts` é o que o `list()` retorna, ou `[número => ['etag' => …]]`
montado com os ETags que quem enviou recebeu. Uma conclusão que falha deixa o upload aberto:
complete de novo, ou aborte.

```php
public function abort (string $path, string $id): bool
```

Aborta o upload e libera suas partes. Um upload que o serviço não conhece mais conta como
abortado.

### S3\Signer

```php
public function __construct (string $key, string $secret, string $region = 'us-east-1', string $service = 's3', string $token = '')
```

Vincula um assinador a um conjunto de credenciais e a um escopo de assinatura. `$token` é o token
de sessão de credenciais temporárias. Lança exceção quando a chave, a região, o serviço ou o
token têm um espaço ou um caractere de controle.

```php
public function sign (string $method, string $host, string $path, array $query, array $headers, string $payload, null|int $time = null): array
```

Assina uma requisição para header auth e retorna os headers a adicionar a ela: `Authorization`,
`x-amz-date`, `x-amz-content-sha256` e, com um token de sessão, `x-amz-security-token`. Todo
header em `$headers` é assinado, então envie todos. `$path` é o path da requisição
percent-encoded, `$host` é o header `Host` como enviado, `$payload` é o SHA-256 do corpo em hex
minúsculo ou `Signer::UNSIGNED`.

```php
public function presign (string $method, string $host, string $path, array $query, int $expires, null|int $time = null): string
```

Assina uma requisição para query auth e retorna sua query string, com a assinatura por último.
Só o header `Host` é assinado, e o payload não.

```php
public static function encode (array $query): string
```

A query string canônica de parâmetros raw: percent-encoded conforme a RFC 3986 e ordenada.
