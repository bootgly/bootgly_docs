# Select

Os três demos oficiais do Select rodam ao vivo abaixo — código real do framework em PHP 8.4 WebAssembly, no seu navegador, **totalmente interativos**.

## Seleção interativa

Escolha uma variação nas abas, aperte Run e **clique no terminal** para dar o teclado a ele: **↑/↓** movem a mira, **Espaço** alterna, letras filtram, **Enter** confirma.

Cada aba é um demo oficial: seleção única com marcas radio, seleção múltipla com marcas checkbox e uma linha travada só-exibição, e uma lista longa janelada com o filtro type-ahead. As opções selecionadas são impressas quando você confirma.

Use o botão de source no terminal para ler o arquivo PHP exato por trás de cada aba. O componente está documentado no [overview do Select](/manual/CLI/UI/Components/Select/overview).
